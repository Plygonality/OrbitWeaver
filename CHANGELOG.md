# Changelog

## 0.1.0 — 2026-10-15

- Newtonian two-body Keplerian array designer with seeded shells, ring families, and inclination families.
- Vectorised safeguarded Halley solver, inertial states, and manifest / NPZ / chunked export.
- Interval screening with a documented \(V \Delta t / 2\) miss bound, local refinement, and an HTML report.
- Blender preview add-on that instances a point cloud in render space, with scientific coordinates kept separate.
- Optional IAS15 comparison when REBOUND is installed. A missing install stays unverified.
- Reference, elliptical, close-approach, collector-shell, ring-family, invalid, and visual-only examples.
